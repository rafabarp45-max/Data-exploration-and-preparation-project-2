# Data Exploration and Preparation - Spambase Dataset

## Project Overview
This project focuses on the essential stage of the data science lifecycle: **Data Exploration and Preparation**. Using the "Spambase" dataset, I performed a comprehensive cleanup and exploratory analysis to prepare the data for future machine learning classification tasks.

## Tools & Environment
* **Language:** Python
* **Environment:** Jupyter Notebook
* **Libraries:** Pandas, Seaborn, Matplotlib, NumPy

## Key Features & Workflow
1. **Data Integrity:** Identification and handling of duplicate records and initial shape analysis.
2. **Data Cleaning:** Removal of irrelevant identifiers (e.g., 'Unnamed: 0') to ensure model quality.
3. **Exploratory Data Analysis (EDA):** Visual investigation of word-frequency attributes.
4. **The Curse of Dimensionality:** A technical analysis of how the 57 attributes impact model performance and the risks of overfitting.

## How to use
The analysis is contained within the `Data_Exploration_Preparation_Spambase.ipynb` file. You can also view the static version in the `Data_Exploration_Preparation_Spambase.pdf` file included in this repository.
